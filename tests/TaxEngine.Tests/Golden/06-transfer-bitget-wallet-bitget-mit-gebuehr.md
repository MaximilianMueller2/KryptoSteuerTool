# Transfer Bitget → Wallet → Bitget mit Gebühr, Frist läuft weiter

Steuerjahr der Auswertung: 2025. Eingabe und erwartetes Ergebnis stehen in `06-transfer-bitget-wallet-bitget-mit-gebuehr.json`.

## Hand-Rechnung

Kauf 1 BTC (Bitget) am 10.01.2025 für 20.000 EUR (20.000 je BTC).

- 01.02.2025: Auszahlung 0,9995 BTC + 0,0005 BTC Netzwerkgebühr (zusammen 1,0) → Eingang Wallet 0,9995. Kosten übertragen: 20.000 × 0,9995 = 19.990;
  der Gebührenanteil 0,0005 BTC ist ein Abgang ohne Erlös, steuerlich neutral (Option a).
- 01.03.2025: Auszahlung 0,9990 + 0,0005 Gebühr (zusammen 0,9995) → Eingang Bitget 0,9990. Kosten 19.990 × 0,9990 / 0,9995 = 19.980 (Stückkosten bleiben 20.000).
- Das Anschaffungsdatum **10.01.2025 bleibt erhalten**. Verkauf 0,999 BTC am 01.06.2025 für 29.970 EUR (30.000 je BTC):
  Gewinn 29.970 − 19.980 = **9.990**; Haltetage 10.01. → 01.06.2025 = 31 + 28 + 31 + 30 + 22 = **142**.
- Netzwerkgebühren gesamt 0,001 BTC (gesondert ausgewiesen). Endbestände: Bitget 0, Wallet 0.
