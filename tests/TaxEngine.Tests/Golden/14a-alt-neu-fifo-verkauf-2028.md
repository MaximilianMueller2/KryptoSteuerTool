# Alt- und Neu-Lots in einer Wallet, FIFO

Steuerjahr der Auswertung: 2028. Eingabe und erwartetes Ergebnis stehen in `14a-alt-neu-fifo-verkauf-2028.json`.

## Hand-Rechnung

Eine Wallet, Reform AN. Lot A (Alt): 01.06.2026, 30.000 EUR. Lot B (Neu): 01.06.2027, 50.000 EUR. Verkauf 1 BTC am 01.03.2028 für 70.000 EUR.

**FIFO:** Lot A (Alt) wird verbraucht: Gewinn 70.000 − 30.000 = 40.000. Haltetage 639 (365 bis 01.06.2027 + 274); steuerfrei ab 02.06.2027 → **steuerfrei**.
Restbestand: Lot B (Neu), Kosten 50.000.
